# Brag Plan: Multi-Agent AI Engineering System — Autonomous Coding Agent

## What is this app?
An autonomous software engineering system powered by LangGraph multi-agent orchestration that takes real coding tasks from repository exploration, AST parsing, and surgical implementation to independent unit/edge-case test generation, isolated subprocess sandbox execution, and adversarial security review.

## The angle
**"Don't just generate code. Engineer, test, debug and verify."**
A premium product launch AND user onboarding experience centered around the actual interactive frontend dashboard: teaching first-time developers how to delegate an entire coding task to an autonomous team of 5 specialized agents.

## Hook (first 3 seconds)
Full dashboard overview showing live controls, LangGraph state machine, and status indicators.
Headline: **"What if you could delegate an entire coding task to an AI engineering team?"**
Voiceover: *"What if you could delegate entire coding tasks to an AI team?"*

## User Journey (4 Steps)
1. **Step 1: Give the agent a repository (3.2s – 6.5s)**:
   - User connects repository via Local Path (Copy-on-Write), GitHub URL, ZIP Upload, or Greenfield from scratch.
   - Voiceover: *"Connect your repo, upload a ZIP, or start from scratch."*
2. **Step 2: Describe the task (6.5s – 9.8s)**:
   - User inputs real requirement (`Refactor passwd-gen.py into a modular password generator with validation, symbol support and password strength calculation`) and selects `⚡ Self-Healing Demo` with Reviewer Gate.
   - Voiceover: *"Just describe what you need. No manual prompt breakdown."*
3. **Step 3: Let the agents collaborate (9.8s – 16.0s)**:
   - LangGraph pipeline animates: AST Indexer ➔ Manager / Plan ➔ Coder ➔ Test-Gen ➔ Sandbox Pytest ➔ Debugger (Self-Healing) ➔ Reviewer ➔ Outcome Report.
   - Live Terminal streams real events.
   - Voiceover: *"Five agents collaborate: planning, coding, and sandboxed self-healing."*
4. **Step 4: Inspect the results (16.0s – 21.8s)**:
   - User inspects the 4 observability tabs: AST Symbol Map, Sandbox & Tests (4 passed in 0.28s), Final Report, and Baseline vs Multi-Agent benchmark.
   - Voiceover: *"Inspect the symbol map, live tests, and verified outcome report."*
