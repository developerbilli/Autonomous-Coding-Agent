# Repository Agent Guidelines & Operating Rules

## Artifact & Output Location Policy

To preserve a clean, production-grade workspace root, strictly adhere to the following output location policies:

### 1. Archify Artifacts (`.archify/`)
- **Strict Rule**: All Archify diagrams, architecture flows, sequence diagrams, explainers, candidate JSON files, test receipts, and final exported HTML files **MUST** be generated or stored strictly inside `.archify/` (or its timestamped subfolders `.archify/<type>-<slug>-<YYYYMMDD-HHMMSS>/`).
- **Forbidden**: Never output Archify `.html`, `.json`, or `.png` exports directly into the project root directory.
- When running `finalize`:
  ```bash
  node bin/archify.mjs finalize <type> .archify/<folder>/candidate.json .archify/<slug>.html --quality showcase --json
  ```
- Any links in documentation (`README.md`, guides, interview manuals) must reference `.archify/<slug>.html`.

### 2. Brag Launch Videos & Media (`brag-output/`)
- **Strict Rule**: All launch films, MP4 renders, poster images (`brag.jpg`), intermediate frames, stems, and share-copy generated by `/brag` or `/brag-slim` **MUST** be placed in `brag-output/` (or `brag-output-<YYYY-MM-DD-HHmmss>/`).
- **Forbidden**: Never place `brag.mp4`, `brag.jpg`, or temporary work media directly in the project root directory.
- Any media links in documentation must reference `brag-output/brag.mp4` and `brag-output/brag.jpg`.

### 3. Documentation & Technical Manuals (`docs/`)
- **Strict Rule**: All architectural guides, interview manuals, benchmark specifications, decision records, and evaluation reports **MUST** reside inside `docs/` (or `docs/reports/`).
- Only `README.md` and this machine instruction file `AGENTS.md` are permitted at the repository root.
